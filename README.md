# dGaspar site

Site institucional dGaspar, feito com Astro e conteúdo em português do Brasil.

## Desenvolvimento

Requer Node.js 22.22 ou superior.

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

O build de produção é gerado em `dist/`. Dependências, saídas de build, caches,
relatórios locais e configurações de editor ficam fora do controle de versão.
